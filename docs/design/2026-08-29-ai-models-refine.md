# AI 模型管理页精修方案

日期：2026-08-29

## 当前版问题诊断

1. 内容区像浅色模板半成品。截图中主内容是大面积白色面板，只有左侧导航是深色，页面没有形成完整的深色控制台环境，深色科技感被割裂成“暗色侧栏 + 白色配置表”。
2. 层级失控。`模型节点墙`、模型名称、摘要数字和操作按钮都使用过重字重，视觉焦点同时落在多个地方；真正重要的默认路由、启用状态、密钥状态反而不够快读。
3. 布局没有墙感。模型卡片没有形成网格卡片，内容沿左侧纵向堆叠，右侧大片空白，导致页面像 CSS 没加载完整的草稿。
4. 信息块不可扫描。`Provider Code`、模型标识、Base URL、接口状态、密钥状态挤成连续文本，标签和值之间没有固定列宽，也没有分隔线，长 URL 与中文混排后非常粗糙。
5. 字体使用不克制。Space Grotesk 覆盖到过多中文标题和按钮，中文笔画显重、发胀，与英文数字混排时出现“粗黑块”观感。
6. 颜色不成立。浅蓝 chip 放在白色面板上显得像默认 Ant Design 标签，主按钮蓝色过亮但周围没有暗色承托，状态色和边框没有系统层级。
7. 组件细节粗糙。按钮过大且文本在窄按钮内换行，`设为默认` 和 `停用` 被挤成竖排；图标按钮边框、圆角、间距不稳定，删除按钮突兀。
8. 摘要带像普通文本。全站默认、可用模型、停用模型只是三行文本，没有数据卡片、状态分组或容器层级，无法承担页面概览作用。
9. 卡片缺少产品语义。节点编号、默认路由、供应商名称、模型 ID、密钥状态没有被组织成“节点面板”，不像管理 AI 供应商，更像把字段直接打印到页面上。
10. 空态、弹窗和路由区缺少统一语言。上一版文档写了 Ant Design dark token，但实际落地没有形成暗面、边框、动效、控件密度的统一系统。

## 打磨方案

### 配色与暗面层次

- 页面背景改为近黑蓝灰 `#080b12`，叠加极弱冷光和细网格，只服务层级，不做霓虹装饰。
- 面板使用 `rgba(14,20,31,.94)` 到 `rgba(10,15,24,.96)` 的暗色渐变，边框控制在 `rgba(137,160,190,.16)` 到 `.28`。
- 主色保留蓝色，但降低纯度，以 `#2f7cff`、`#71a8ff` 表达操作和默认路由；状态色使用绿色、琥珀、红色的低透明背景。
- 移除白色大面板、浅蓝大胶囊和孤立强阴影，改用暗色边框、内部分隔线和轻微冷光。

### 字体与排版

- 中文标题和正文回到系统中文字体栈，保证字形清晰；Space Grotesk 只用于编号、短 code、数字等技术标识。
- 主标题从过大的英雄字号收敛到 38px，模块标题为 24px，卡片标题为 22px，详情值为 13px 等宽风格。
- 所有中文按钮避免窄宽度换行；图标按钮只显示图标，文字保留在 `aria-label` / `title` / `sr-only` 中。

### 布局与间距

- 顶部改为深色状态头，左侧是页面名称和说明，右侧是启用 / 停用节点数据。
- 模型区保持一整个控制台面板，摘要带改为三张紧凑数据卡。
- 模型列表改为 2 列、宽屏 3 列、自适应单列的节点墙，每张卡片内部按“头部状态 -> 身份 -> 详情键值 -> 操作栏”排列。
- 详情区域改为固定标签列 + 值列的键值表，长 code 和 URL 使用 `overflow-wrap:anywhere`。

### 卡片与组件细节

- 默认节点使用更亮蓝色边框和顶部细光条；停用节点降低透明度但不破坏可读性。
- 状态使用点状灯 + 语义 pill：运行中、已停用、默认路由分层呈现。
- 操作按钮统一 38px 图标按钮，hover 时只提升边框和背景，不制造大面积发光。
- Modal 使用暗色浮层、细边框、柔和遮罩和轻量进出场动画；表单控件与页面 token 保持一致。

### 状态与信息层级

- 页面首先让用户看见启用数量、停用数量和默认路由。
- 单张模型卡优先展示显示名、供应商类型、运行状态和默认标记。
- 技术字段放入键值表，降低视觉噪音，同时保持运维可复制和可扫描。
- 业务路由区使用同一暗色卡片语言，业务 code 与当前模型分开显示。

## 被推翻或修改的旧实现

- 推翻白底主内容区和浅蓝大胶囊风格。
- 推翻模型字段连续文本打印的结构，改成节点卡片和键值表。
- 修改 Space Grotesk 的使用范围，避免中文标题和正文过度使用拉丁展示字体。
- 修改摘要信息，从普通三行文本改为独立状态数据卡。
- 修改操作区，避免窄按钮中文换行，统一为图标工具条。
- 保留 server actions、字段名、弹窗表单、删除确认、JSON 校验和业务路由保存逻辑。

## 关键取舍记录

- 不引入 Ant Design 或其它 npm 依赖，只用现有 JSX 与 CSS 复刻成熟暗色中后台语言。
- 科技感靠暗面层次、网格、状态灯和信息密度表达，不做霓虹赛博风。
- 为了不影响后端契约，表单字段和 action 全部保持不变；本轮主要调整视觉结构和 CSS。
- 全局 admin 暗色 token 会让其它管理页更接近同一气质，但本轮重样式主要作用在 `.ai-models-*`、`.image-model-*`、`.usage-*` 范围。
