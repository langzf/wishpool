## 选定结论

本页选定 **Ant Design 5 暗色模式** 作为设计基底。

原因：

- AI 模型管理页本质是中后台配置中心，包含表单、状态标签、弹窗、危险操作和路由选择，Ant Design 的组件心智最稳。
- Ant Design 5 的 token 模型适合手工落地到 CSS 变量，不需要安装组件库，也能复刻主色、圆角、阴影、表单和 Modal 行为。
- 用户偏好深色科技感，Ant Design 官方暗色模式强调暗环境、内容聚焦和层级控制，适合管理端。
- ByteDesign / Arco 的 AI 产品气质会作为补充：更紧凑的数据块、更像控制台的状态灯、供应商矩阵，而不是传统表格或白色列表。

## 落地方案

### 样式 token

在 `apps/admin-web/app/styles.css` 以 `:root` 落地一套 Ant Design 5 dark 派生 token：

| Token 类别 | 变量 |
| --- | --- |
| 主色 | `--color-primary: #1677ff`、`--color-primary-hover: #4096ff`、`--color-primary-active: #0958d9` |
| 功能色 | `--color-success: #49aa19`、`--color-warning: #d89614`、`--color-danger: #ff4d4f`、`--color-info: #1677ff` |
| 暗色中性面 | `--color-background: #070b16`、`--color-surface: #111827`、`--color-surface-raised: #182033`、`--color-elevated: #1f293d` |
| 文本 | `--color-foreground: #f0f5ff`、`--color-text-secondary: #b6c2d6`、`--color-text-tertiary: #7f8ba3` |
| 边框 | `--color-border: rgba(120, 146, 184, 0.22)`、`--color-border-strong: rgba(120, 146, 184, 0.36)` |
| 字号 | 12 / 13 / 14 / 16 / 20 / 28 / 44 |
| 圆角 | 4 / 6 / 8 / 12；卡片和控件默认不超过 8px，符合项目基线 |
| 阴影 | 暗色浮层阴影 `0 18px 50px rgba(0,0,0,.34)`，按钮与弹窗使用更强投影 |
| 间距 | 4 / 8 / 12 / 16 / 20 / 24 / 32 / 40 / 48 |
| 动效 | 120ms / 180ms / 240ms，`cubic-bezier(0.2, 0, 0, 1)` |

### 暗色科技感取舍

页面采用 Ant Design dark 的深色层级：深背景、抬升面、边框分层、蓝色主按钮、绿色/黄色/红色语义状态。科技感只通过控制台网格、细线边框、状态灯、数字字体和局部冷光表达，不使用大面积紫蓝渐变、霓虹装饰或赛博风。

### 字体方案

- 拉丁、数字、标题：`Space Grotesk`，Google Fonts / SIL Open Font License，下载到 `apps/admin-web/public/fonts/space-grotesk-latin-500-700.woff2`，大小约 22 KB。
- 中文：`PingFang SC`, `MiSans`, `Noto Sans SC`, `Microsoft YaHei`, 系统 sans-serif。
- CSS 使用 `@font-face` 本地引用，禁止外链字体和 CDN。

### 全新列表形态

模型供应商不再使用一列一行卡片列表，改为 **模型控制台网格墙**：

- 顶部为运行概览数据带：默认模型、启用数、停用数。
- 主体为 2-3 列自适应模型卡片墙，每张卡片像控制台节点：状态灯、供应商类型、模型标识、密钥状态、接口状态、操作工具条。
- 默认模型以蓝色边框和“默认路由”标记强调；停用模型降低透明度但仍可扫描。
- 业务默认模型改为 **路由矩阵**，三种业务场景并列展示当前绑定、可选模型与保存操作。

### 交互规格

- Hover / active：卡片边框升亮、轻微上移；按钮遵循 Ant Design primary / default / danger 层级。
- 提交 pending：所有 server action 按钮显示旋转 Loader 和中文处理中状态。
- Modal：遮罩淡入，面板轻微缩放和上移，移动端贴底弹出；支持 Escape 和点击遮罩关闭。
- 删除二次确认：行内展开确认条，中文“确认删除？”、“确认删除”、“取消”，默认模型禁删。
- `extra_params` 实时 JSON 校验：输入时即时校验，仅允许 JSON 对象；中文错误提示；错误态红色边框。
- 空态：显示暗色虚线控制台空态，引导新建模型。
- 加载态：服务端页面保持现有 Next.js 请求模型；表单 pending 覆盖提交加载态。
- 成功 / 失败反馈：顶部 toast 使用语义色、图标和中文提示。
- 移动端：网格退化为单列，操作按钮保持 44px 触控目标，弹窗最大高度滚动。

## 与旧版差异声明

被替换 / 禁止沿用：

- 禁止浅色大背景、白色大面板和系统默认字体。
- 禁止逐行列表式模型渲染。
- 禁止大圆角糖果按钮和旧版浅色 SaaS 卡片堆叠。
- 禁止 Google Fonts 外链。
- 禁止将供应商、模型、密钥、状态信息挤成平庸横向行。

新方案替换为：

- Ant Design 5 dark token 基底。
- 本地 `Space Grotesk` 展示字体 + 中文系统字体栈。
- 模型控制台网格墙和业务路由矩阵。
- 暗色 Modal、状态灯、语义标签、行内确认和实时 JSON 校验。
