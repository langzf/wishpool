# WishPool Project Code Structure

## Project Purpose

WishPool（星愿小屋）是一款面向家庭内部使用的儿童成长陪伴 App。产品目标是完整承载“周日许愿 -> 每日任务 -> 儿童多媒体打卡 -> AI 辅助预审 -> 家长快速审核反馈 -> 星光/心愿碎片 -> 周末心愿兑现 -> 成长纪念册 -> 小屋展示”的家庭闭环，并具备多客户端、自有业务后端、AI/媒体处理、实时同步、隐私治理和运营支持能力。

当前仓库已建立产品技术设计文档、工程基础、API 契约、数据库迁移、Core API、工作流 worker、实时同步网关、媒体处理 worker、AI worker、通知服务、Admin API、移动端、家长 Web、管理后台、设计令牌和样例数据。采用 Flutter/Dart 构建移动和平板 App，Next.js/TypeScript 构建 Web 与后台，Kotlin/Spring Boot 构建核心业务后端，Kotlin/Ktor 构建实时同步网关、通知服务和 Admin API，Python 构建 AI 与媒体处理 worker，PostgreSQL 作为事实库。
